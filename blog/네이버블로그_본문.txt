[제목]
카톡 단톡방 일정을 단축어 한 번으로 구글 캘린더에 넣기 (iOS 단축어 + Apps Script + Claude API)


■ 들어가며

카톡 메시지를 복사하고 단축어를 한 번 누르면, AI가 일정과 소품 변경을 뽑아 구글 캘린더에 넣어 주는 도구를 만들었습니다. 들인 비용은 API 크레딧 5달러가 전부이고, 서버도 따로 두지 않았습니다.

시작은 친구의 하소연이었습니다. 업무 단톡방에 이런 메시지가 하루에도 몇 번씩 올라온다고 했습니다.

"15일 촬영 3시 시작으로 한 시간 미뤄졌어요"
"그리고 의자는 10개 말고 12개로 늘려주세요"

친구는 그때마다 캘린더를 열어 해당 일정을 찾고, 시간을 고치고, 메모에 소품 수량을 다시 적었습니다. 한 번은 1분이면 끝나는 일이지만, 하루 몇 번씩 반복되고 빠뜨리면 사고가 납니다. 그래서 이 작업을 자동화해 보기로 했습니다.


■ 완전 자동이 아니라 반자동인 이유

카톡 메시지를 자동으로 읽어 올 방법이 아이폰에는 없어서, '복사 후 버튼 한 번'을 택했습니다. 먼저 확인해 본 제약은 이렇습니다.

• 카카오톡에는 단톡방을 읽는 공식 API가 없습니다. 챗봇을 단톡방에 넣어 메시지를 읽는 것도 일반 단톡방에서는 어렵습니다.
• 아이폰은 다른 앱의 알림을 읽을 수 없습니다. 안드로이드라면 카톡 알림을 가로채는 앱으로 완전 자동화도 가능하지만, 친구는 아이폰만 씁니다.
• PC 카톡 창을 긁어오는 방식은 PC를 항상 켜 둬야 하고, 카톡 업데이트 한 번에 깨지기 쉽습니다.

그래서 입력은 사람이 하고, 나머지는 프로그램이 맡는 구조로 정했습니다. 또 AI가 바로 캘린더를 고치지 않고, 미리보기를 보여 준 뒤 승인해야만 반영하도록 했습니다. 업무 일정이 잘못 들어가면 손으로 입력하는 것보다 더 큰 문제가 되기 때문입니다.


■ 전체 구조

사람은 복사와 승인만 하고, 나머지는 구글 서버에서 도는 Apps Script 웹앱과 Claude API가 처리합니다.

[이미지: 흐름도.png 업로드]

웹앱은 분석 결과를 바로 반영하지 않고 미리보기로 돌려보냅니다. 캘린더는 '반영'을 눌렀을 때만 바뀝니다.


■ 구현 1. Google Apps Script 웹앱

서버는 Google Apps Script 웹앱 하나로 끝냈습니다. 무료이고, 구글 캘린더를 내 권한으로 바로 다룰 수 있고, PC를 켜 둘 필요가 없습니다. 코드는 로컬에서 작성하고 구글 공식 CLI인 clasp로 올렸습니다.

파일 구성
• Code.gs : 웹앱 입구(parse / apply), 미리보기 문구
• Claude.gs : Claude API 호출과 프롬프트
• Calendar.gs : 일정 생성·수정·취소 표시, 소품 기록
• State.gs : 대화 내보내기 파일 읽기, 중복 방지
• Users.gs : 여러 사용자 등록·횟수 제한 (뒤에서 추가)

설계에서 신경 쓴 부분은 다섯 가지입니다.

1. 분석과 반영을 두 단계로 나눔
parse 요청은 분석 결과를 캐시에 10분 보관하고 토큰과 미리보기만 돌려줍니다. 승인하면 그 토큰으로 apply를 불러 실제로 반영합니다. 그래서 AI를 다시 부르지 않고, 본 내용 그대로 들어갑니다.

2. 기존 일정과 매칭
분석 전에 캘린더의 지난 7일~앞으로 90일 일정을 함께 넘깁니다. "3시로 미뤄졌어요" 같은 변경 공지가 오면 새 일정을 만들지 않고 기존 일정을 고칩니다.

3. 소품은 설명란의 [소품] 섹션에만 기록
나머지 메모는 건드리지 않고, 소품 이름 기준으로 수량만 갱신합니다.

4. 취소 공지는 삭제하지 않음
제목 앞에 [취소]만 붙여서, AI가 잘못 판단해도 쉽게 되돌릴 수 있게 했습니다.

5. 대화 내보내기 중복 방지
밀린 공지는 단톡방 '대화 내용 내보내기' 파일로 한꺼번에 보낼 수 있습니다. 마지막으로 처리한 메시지 시각을 저장해 두고 그 뒤 메시지만 분석합니다.

소품 기록은 캘린더 일정 설명에 이렇게 남습니다.

[소스코드]
[소품]
- 의자: 12개 (10개→12개, 11/10 변경)
- 조명: 2개 (11/10 변경)
[소스코드 끝]


■ 구현 2. Claude API로 문장 이해하기

"다음주 수요일", "10개 말고 12개로" 같은 말을 날짜와 수량으로 바꾸는 일은 Claude API(claude-sonnet-5-5)에 맡겼습니다. 정규식으로는 사람마다 다른 말투를 따라갈 수 없었습니다.

프롬프트에 넣은 규칙은 이렇습니다.
• 일정 공지, 변경·취소, 소품 수량만 뽑고 "넵", "확인했습니다" 같은 잡담은 무시한다.
• 상대 날짜는 메시지가 올라온 시각 기준으로 계산한다.
• 기존 일정과 같은 건이면 새로 만들지 말고 그 일정을 수정한다.
• 확실하지 않으면 추측하되 확신도를 low로 표시한다. 미리보기에 ⚠ 표시가 붙습니다.

결과는 코드가 바로 쓸 수 있게 JSON으로 받아야 합니다. 처음에는 도구 호출을 강제하는 tool_choice를 썼는데, 실제 호출에서 바로 오류가 났습니다.

[소스코드]
tool_choice: type "tool" and "any" are not supported for this model.
[소스코드 끝]

최신 모델에서는 강제 도구 호출이 막혀 있었고, 대신 structured outputs를 써야 했습니다. 요청에 JSON 스키마를 넣으면 응답이 그 형식에 맞게 나옵니다.

[소스코드 - JavaScript]
const payload = {
  model: 'claude-sonnet-5-5',
  max_tokens: 16000,
  system: buildSystemPrompt_(cfg),
  output_config: {
    effort: 'medium',
    format: { type: 'json_schema', schema: ACTIONS_SCHEMA_ },
  },
  messages: [{ role: 'user', content: '## 기존 캘린더 일정\n' + events + '\n\n## 카톡 메시지\n' + text }],
};
[소스코드 끝]

응답에서는 content 중 text 블록을 찾아 JSON.parse 하면 됩니다. 스키마의 각 객체에는 additionalProperties: false를 넣었습니다. 모델이 정해진 칸 밖의 내용을 넣지 못하게 하려는 것입니다.

수정 후 테스트한 결과는 이랬습니다.
• "15일 오후 2~4시 성수동 스튜디오 촬영, 의자 10개, 조명 2개" → 새 일정 등록, 소품 2건 기록
• "3시로 한 시간 미뤄짐, 의자 12개로" → 기존 일정을 찾아 시간 15:00~17:00, 의자 10→12개로 수정
• "넵 확인했습니다 감사합니다" → "일정·소품 관련 내용이 없습니다"


■ 구현 3. iOS 단축어

아이폰 쪽은 기본 앱인 '단축어'로 만들었습니다. 새로 설치한 앱은 없습니다. 카톡에서 메시지를 복사하고 단축어를 누르면 클립보드 내용이 웹앱으로 갑니다.

동작 순서는 이렇습니다.
1. 공유 시트에서 입력 받기 (입력이 없으면 클립보드 가져오기)
2. URL의 콘텐츠 가져오기 : POST, JSON 본문 secret, action=parse, text
3. 사전 값 가져오기 × 2 : summary(미리보기 문구), token
4. 조건문 : token에 값이 있으면
   - 메뉴에서 선택 (프롬프트 = 미리보기, 항목 = 반영 / 취소)
   - 반영 : URL의 콘텐츠 가져오기(action=apply, token) → 결과 알림
5. 그렇지 않으면 : "관련 내용 없음" 같은 안내를 알림으로 표시

만들면서 헷갈렸던 지점은 세 군데였습니다.
• '만약'이 아니라 '조건문'. 최신 iOS에서는 If 동작의 한국어 이름이 조건문입니다. 추가하면 입력이 '파일 크기' 같은 속성으로 잡힐 수 있어서, '변수 선택'으로 다시 골라야 합니다.
• 두 번째 '사전 값 가져오기'의 대상. 추가하면 바로 앞 동작의 결과가 자동으로 잡힙니다. 대상을 'URL 콘텐츠'로 바꿔야 합니다.
• 복제한 블록의 필드 이름. 반영용 요청은 첫 요청을 복제해서 만들었는데, 필드 키를 text에서 token으로 바꾸는 걸 놓치기 쉽습니다.

실제로 카톡에 "16일 월요일 오전 11시 회의실B에서 소품 회의, 테이블 3개 필요"를 보내고 단축어를 돌려 보았습니다. 미리보기에 "[새 일정] 소품 회의 · 11/16(월) 11:00, 장소: 회의실B, 소품: 테이블 3개"가 떴고, 반영을 누르자 캘린더에 그대로 들어갔습니다. 끝나는 시간이 없는 공지는 1시간짜리 일정으로 들어갑니다.


■ 다른 사람도 쓰게 확장하기

친구가 쓸 수 있게 하려면 방법이 두 가지였고, 나중에 모르는 사람도 쓸 수 있도록 캘린더 공유 방식을 골랐습니다.

A. 각자 설치
• 새 사람 추가 : 내가 그 사람 구글 계정으로 로그인해 설치
• 코드 업데이트 : 설치된 곳마다 다시 배포
• API 키 : 각 프로젝트에 들어가 상대가 볼 수 있음
• 캘린더 접근 : 내가 친구 캘린더를 볼 수 없음
• 비용 통제 : 키별 월 한도

B. 하나에 캘린더 공유 (선택)
• 새 사람 추가 : 본인이 캘린더 공유 → 등록 페이지 → 단축어 추가 (5분)
• 코드 업데이트 : 한 번이면 모두 적용
• API 키 : 내 계정에만 있음
• 캘린더 접근 : 공유받은 캘린더를 내가 볼 수 있음
• 비용 통제 : 월 한도 + 1인당 하루 횟수 제한

B 방식은 구글 캘린더의 기본 공유 기능만 씁니다. 그래서 "구글로 로그인" 앱을 만들 때 필요한 구글 앱 심사가 필요 없습니다. 추가한 것은 이렇습니다.

• 등록 페이지 : 웹앱 주소를 브라우저로 열면 나오는 페이지입니다. 캘린더 만들기, 공유, ID 복사 순서를 안내하고, 입력하면 개인 코드를 발급합니다.
• 연결 확인 : 등록할 때 테스트 일정을 만들었다 바로 지워서, '보기'만이 아니라 '일정 변경' 권한으로 공유했는지 확인합니다.
• 개인 코드 : 단축어의 secret 칸에 들어갑니다. 코드마다 연결된 캘린더와 처리 기록이 따로 관리됩니다.
• 초대 코드 : 등록 페이지 링크가 퍼져도 초대 코드를 모르면 등록할 수 없습니다.
• 하루 20회 제한 : 1인당 분석 횟수를 제한해 비용이 새지 않게 했습니다.
• 내 캘린더 등록 차단 : 다른 사람이 관리자 자신의 캘린더를 등록해서 건드리는 일을 막았습니다.

단축어는 내 것을 복제하고 secret 값을 '가져오기 질문'으로 바꿔서 iCloud 링크로 나눠 줍니다. 받는 사람은 단축어를 추가할 때 자기 개인 코드만 붙여넣으면 됩니다.


■ 비용과 보안 체크리스트

운영 비용은 Claude API 크레딧뿐이고, Apps Script와 단축어는 무료입니다. Claude API는 크레딧을 미리 충전해야 하는데, 테스트용으로 5달러(세금 포함 5.5달러)를 넣었습니다. 한 번 처리할 때 카톡 메시지 몇 건과 캘린더 일정 목록이 같이 전송됩니다. 실제 사용량은 콘솔의 Usage 메뉴에서 확인할 수 있습니다.

☐ API 키는 이 용도 전용으로 따로 발급한다. 문제가 생기면 이 키만 삭제하면 즉시 멈춘다.
☐ 콘솔에서 월 사용 한도를 걸고, 자동 충전은 끈다.
☐ 웹앱은 "모든 사용자" 접근이므로, 개인 코드가 맞는 요청만 처리하게 한다.
☐ 웹앱 주소, 비밀번호, 초대 코드, API 키는 블로그나 단톡방에 올리지 않는다.
☐ 사용자에게는 개인 캘린더 대신 업무용 캘린더를 새로 만들어 공유하라고 안내한다.
☐ 관리자 구글 계정에는 2단계 인증을 켜 둔다. 이 계정이 털리면 공유받은 캘린더가 모두 노출된다.
☐ 카톡 내용은 구글 Apps Script와 Anthropic API로 전송된다는 점을 사용자에게 미리 알린다.


■ 마치며

이제 카톡 공지 하나를 캘린더에 옮기는 일이 '복사, 단축어, 반영' 세 번의 탭으로 끝납니다. 기존 일정을 찾아 고치고, 소품 수량 변경 이력까지 남는 게 가장 만족스럽습니다.

아쉬운 점과 다음에 해볼 것도 있습니다.
• 아이폰에서는 여전히 복사를 사람이 해야 합니다. 안드로이드 공기계를 하나 두고 카톡 알림을 가로채면 완전 자동화도 가능합니다. 이때도 지금 만든 웹앱을 그대로 쓸 수 있습니다.
• 끝나는 시간이 없는 공지는 일단 1시간짜리로 들어갑니다. 팀마다 기본 길이를 다르게 두면 좋겠습니다.
• 사용자가 많아지면 '구글로 로그인' 방식으로 옮겨서, 관리자가 남의 캘린더를 볼 수 있는 구조 자체를 없애고 싶습니다. 100명을 넘으면 구글 앱 심사가 필요합니다.
